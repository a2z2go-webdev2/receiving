# UI Components

The frontend follows Laravel's official React starter kit conventions:

- Base primitives live in `resources/js/components/ui`.
- Larger composed blocks can live in `resources/js/components/blocks`.
- Forms, tables, modals, and common components have their own folders.
- Shared TypeScript types live in `resources/js/types`.

The project is shadcn/ui-compatible. Keep generated primitives small, reusable, and visually consistent with the existing sidebar/layout system.
